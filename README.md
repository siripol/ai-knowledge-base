# AI Knowledge Base

A simple, curated, plain-language collection of the most useful things to read and know
about **AI, Claude, and LLMs** — for everyone, whether you're just starting or building
real products.

No jargon walls, no complexity. Just high-signal links and short notes on why each one
is worth your time.

## Contents

- **[Articles](articles.md)** — the important reads, grouped by topic. Start here.
- **[Recommended Repos](recommended-repos.md)** — open-source projects worth knowing.
- **[Best Practices](best-practices.md)** — short, practical lessons for building with LLMs.

## How to use this

Skim the section that matches where you are. Each entry has a one-line "why" so you can
decide before clicking. Found something great? Add it — see below.

## Contributing

Add an entry as a single bullet in the right file:

```
- [Title](https://link) — source. **Why read:** one plain sentence.
```

Keep it short, keep it useful, avoid duplicates. Newer finds go at the top of their group.
