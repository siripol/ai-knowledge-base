# Recommended Repos

Open-source projects worth knowing for AI, Claude, and LLM work. Each entry says what it
is and why it's useful.

## Learn the fundamentals

- [karpathy/nanoGPT](https://github.com/karpathy/nanoGPT) — minimal, readable GPT training code. **Why:** the fastest way to actually understand how an LLM is built.
- [anthropics/courses](https://github.com/anthropics/courses) — Anthropic's hands-on courses. **Why:** structured lessons on prompting, real-world prompting, and tool use.
- [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide) — the repo behind promptingguide.ai. **Why:** comprehensive, free prompting reference.

## Cookbooks & examples

- [anthropics/anthropic-cookbook](https://github.com/anthropics/anthropic-cookbook) — recipes for building with Claude. **Why:** copy-paste patterns for tool use, RAG, vision, and more.
- [openai/openai-cookbook](https://github.com/openai/openai-cookbook) — practical LLM recipes. **Why:** broad, well-maintained examples that transfer across providers.

## Building agents

- [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) — graph-based agent orchestration. **Why:** control agent flow as a state machine — great for reliable, complex agents.
- [langchain-ai/langchain](https://github.com/langchain-ai/langchain) — the widely-used LLM app framework. **Why:** batteries-included building blocks and a huge ecosystem.
- [crewAIInc/crewAI](https://github.com/crewAIInc/crewAI) — role-based multi-agent framework. **Why:** simple mental model for teams of cooperating agents.
- [microsoft/autogen](https://github.com/microsoft/autogen) — multi-agent conversation framework. **Why:** mature patterns for agents that talk to each other and to tools.

## Retrieval (RAG) & data

- [run-llama/llama_index](https://github.com/run-llama/llama_index) — data framework for LLM apps. **Why:** the go-to for connecting your documents to an LLM.
- [chroma-core/chroma](https://github.com/chroma-core/chroma) — open-source vector database. **Why:** easy local embeddings store to get RAG running fast.

## Claude / MCP

- [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) — reference MCP servers. **Why:** ready-made connectors (files, git, databases) and templates to build your own.
- [modelcontextprotocol/python-sdk](https://github.com/modelcontextprotocol/python-sdk) — official Python MCP SDK. **Why:** the fastest way to expose your own tools to Claude and other clients.

## Run models locally

- [ollama/ollama](https://github.com/ollama/ollama) — run open LLMs on your machine. **Why:** one command to try Llama, Mistral, and others locally and privately.
- [huggingface/transformers](https://github.com/huggingface/transformers) — the standard model library. **Why:** access thousands of models and the tooling around them.

## Awesome-lists

- [e2b-dev/awesome-ai-agents](https://github.com/e2b-dev/awesome-ai-agents) — curated list of AI agent projects. **Why:** a living map of the agent ecosystem when you need to find a tool.
- [f/awesome-chatgpt-prompts](https://github.com/f/awesome-chatgpt-prompts) — big collection of prompt examples. **Why:** quick inspiration for prompt patterns.
